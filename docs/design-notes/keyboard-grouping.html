How the Keyman keyboards group

The 920 keyboards in the Keyman keyboards repository, grouped by writing system. Latin-script keyboards are split by the physical layout they build on (QWERTY, AZERTY, QWERTZ, Dvorak, and others). Inside each group, keyboards are sorted by how they produce characters: Plain (one key, one character), Deadkey only, Context only (rules that look at what was typed before), or Both.

Scripts with only two keyboards are listed together under Pairs, and scripts with a single keyboard under Singleton.

This shows how keyboards cluster, not which keyboard was copied from which. It is a snapshot of the repository at the time of the analysis.
