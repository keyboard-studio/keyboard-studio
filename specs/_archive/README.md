# Retired specs

Full working docs (spec, plan, tasks, research, data-model, contracts, checklists) of shipped features, moved here by `km-retire`.
Don't read these by default. Start from `specs/NNN-slug/AS-BUILT.md`, the one-page as-built summary. The code is the truth.
Open an archived doc only when an AS-BUILT links a specific section or the task is explicitly historical.
Files were moved with `git mv`, so `git log --follow` still carries their history.
